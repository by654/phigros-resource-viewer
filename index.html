📖 如何获取 GitHub Token（点击展开教程）

方式一：经典 Token（Classic，最简单，推荐）

  1. 登录 GitHub，打开 https://github.com/settings/tokens/new
  2. 在 Note 一栏随便填个名字，例如 phigros-downloader。
  3. 在 Expiration 里选择有效期（例如 90 天）。
  4. 权限勾选：只读取公开资源的话，不需要勾选任何 scope。
  5. 滚动到页面底部，点击绿色按钮 Generate token。
  6. 复制以 ghp_ 开头的字符串（离开页面后就看不到了）。

方式二：细粒度 Token（Fine-grained，更安全）

  1. 打开 https://github.com/settings/personal-access-tokens/new
  2. 填写 Token name 与 Expiration。
  3. Repository access 选择 Public Repositories (read-only)。
  4. 点击 Generate token，复制以 github_pat_ 开头的令牌。

注意事项

  • Token 等同于密码，请勿分享给他人。
  • 未填写 Token 时，GitHub 对同一 IP 的匿名请求额度较低，仍可正常使用。
  • 提示 Bad credentials 说明 Token 复制不完整或已失效。
  • Token 仅在访问 GitHub API 时附加，不会附加到静态资源请求（避免 CORS 拦截）。
  • 配置 Token 后，下载线程数会自动提升（默认 4 → 8）。
