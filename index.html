📖 如何获取 GitHub Token（点击展开教程）

方式一：经典 Token

  1. 打开 https://github.com/settings/tokens/new
  2. Note 随便填名字，Expiration 选有效期。
  3. 只读公开资源不需要勾选任何 scope。
  4. 点击 Generate token，复制 ghp_ 开头的字符串。

方式二：细粒度 Token

  1. 打开 https://github.com/settings/personal-access-tokens/new
  2. Repository access 选 Public Repositories (read-only)。
  3. 生成并复制 github_pat_ 开头的令牌。

Token 不会附加到静态资源请求，仅用于 GitHub API 调用。
